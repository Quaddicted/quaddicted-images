Images for https://www.quaddicted.com/db/

Images are stored in the same SHA256-based tree structure as files in https://www.quaddicted.com/files/by-sha256/ and metadata in https://github.com/Quaddicted/quaddicted-data

E. g. images for a file with the SHA256 `98ea6e4f216f2fb4b69fff9b3a44842c38686ca685f3f55dc48c5d3fb1107be4` would go into the directory `quaddicted-images/by-sha256/98/98ea6e4f216f2fb4b69fff9b3a44842c38686ca685f3f55dc48c5d3fb1107be4/`

# For use in the interface at https://www.quaddicted.com/db/
As of 2026-08 the interface at https://www.quaddicted.com/db/:
- Supports multiple images per file.
- Supports arbitrary file names for the images, which will be shown on mouse-over. Please use reasonable file names.
- Supports JPEG, PNG and WebP as source formats.
- Supports arbitrary resolutions and sizes. Please be reasonable.
- Transforms these sources images to appropriate sizes and formats on demand.
